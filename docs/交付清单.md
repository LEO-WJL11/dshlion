## 2. 用户怎么装

1. 双击 `LionBox-Setup-1.1.0.exe`（**一个文件，直接装**）
2. 一路下一步（装在 `%LOCALAPPDATA%\Programs\LionBox`，**不需要管理员权限**，不弹 UAC）
3. 装完桌面和开始菜单会有快捷方式

**不需要用户装 Java** —— 安装包自带精简运行时（`runtime-jre\`，约 52 MB）。
**不需要注册账号**，装完直接用。安装只占约 140MB。

## 3. 首次使用会发生什么（用户最容易疑惑的点，建议提前告知）

1. 双击「LionBox」快捷方式 → 控制台窗口显示 4 步，**5-15 秒**走完
2. **这一步不加载模型**；如果权重还没下过，窗口会写
   「权重：未下载 —— 首次用到时自动从 ModelScope 获取」
3. 浏览器自动打开 <http://127.0.0.1:8080>
4. **发第一条消息时**依次发生两件事：
   - 先从 ModelScope **下载权重 8.9GB**（只有第一次，界面/日志能看到进度）
   - 再加载模型进内存，约 **30-90 秒**
5. 之后再发消息就直接回答；关掉软件后下次启动只需重新加载（权重已在本地）

想提前下好：**设置 → 模型来源 → 下载模型**（只下载、不加载，不占显存）；
想提前加载：同页「立即加载模型」；想释放内存：「卸载模型」。

**离线/内网部署**：把 `lion-merged-Q8_0.gguf` 拷进安装目录（或 `models\` 子目录），
程序优先用本地现成文件，不会联网；要彻底禁止下载就设
`lionbox.runtime.auto-download=false`。

## 4. 环境要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（64 位） |
| Java | **不需要**（自带）；仅手动解压使用的场景才需要 Java 21+ |
| 内存 | 建议 **32 GB**；16 GB 请把上下文降到 32K/64K |
| 磁盘 | 安装约 **140MB** + 权重 **8.9GB**（首次使用时下载），共留 10 GB 以上 |
| 网络 | 仅**首次下载权重**需要联网；之后本地推理完全离线 |
| 显卡 | 可选。有显卡走 Vulkan 自动加速；没有就用 CPU（慢一些） |

## 5. 两种模型来源

- **本地模型（默认）**：完全离线，推理在用户自己机器上，代码和数据不出机器
- **自定义 API**：让用户填自己的 Base URL / API Key / 模型名，任何 OpenAI 兼容服务都行；
  这种模式下**本地模型永不加载**，不占内存显存

切换在 **设置 → 模型来源**，即时生效不用重启。填过的地址/密钥会存起来，
来回切换不会丢（已实测）。

## 6. 卸载与数据

- 卸载：开始菜单 → 卸载 LionBox（或安装目录里的 `unins000.exe`）
- **只删程序，保留用户数据**：会话记录、工作区、配置都在 `%USERPROFILE%\.lioncode\`，
  卸载后还在；要彻底清干净就手动删掉这个目录
- 配置里（`app-config.json`）的 API Key 是**明文**存的（本机文件）。介意的话别填共享电脑。
  程序只监听 `127.0.0.1`，同局域网其他机器访问不到

## 8. 还没验证的（如实说明）

- ⚠️ **真正加载模型跑一轮没做**：以上全部刻意避开 GPU，所以"模型加载 30-90 秒、
  生成 ~11 tokens/秒、一次问答 10-20 秒"这些数字**来自更早的实测，本轮没有复现**
- ⚠️ 界面**观感**没做人眼走查（接口层已核对无误）
- ⚠️ Q8 权重在 16 GB 内存机器上的表现未实测（建议这类用户用 Q4 或降上下文）

## 9. 出问题看哪

| 现象 | 先看这里 |
|---|---|
| 界面打不开 | `%TEMP%\lionbox-agent.log`，以及启动窗口的 4 步提示 |

| 内存不够 / 被系统杀 | 换 Q4 权重或把上下文降到 32K；或切自定义 API 模式 |
| 模型乱调工具 / 回复是空的 | 设置 → 模型来源 → 工具调用方式，换「原生」或「仅文本」 |
