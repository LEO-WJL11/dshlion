# LionBox 硬件设计规格（RK3588S 全自研载板）

> 本文档是模型盒子（LionBox）主板的硬件设计输入。所有已确认的数据都标注来源；
> 未确认的一律标 **【待核对】**，不得作为投板依据。

## 1. 产品目标

用户买回盒子 → 插上电脑 → 电脑自动安装 agent → agent 使用盒子本地部署的模型干活。
全程离线、无 API Key、不使用任何第三方云服务。

**架构分工（已确认）**：

| 部分 | 运行位置 | 理由 |
|---|---|---|
| 模型推理 | **盒子内部** | 用户要求"推理必须发生在盒子内部" |
| Agent 主循环 + 工具执行 | **电脑上** | 需要访问电脑上的文件 |
| 盒子 → 电脑通道 | **USB 复合设备**（U盘 + 网卡） | 实现"插上自动装" |

- LPDDR4/4X：VDDQ = 0.6V（0.57~0.63V），Retention VDDQ = 1.1V（1.045~1.155V）
- LPDDR5：VDDQ = 0.5V（0.475~0.525V），Retention VDDQ = 1.05V（1.0~1.1V）
- DDR PLL 电源：1.8V（1.62~1.98V）

## 3. 模型与性能边界（实测标定）

模型：`MiMo-V2.6-Distill-Qwen-9B-Q4_K_S.gguf`
- 文件 5,483,255,328 字节（5.48 GB），8.95B 参数，Q4_K_S
- 架构 `qwen35`（Qwen3.5-9B 基座），32 层
- 混合注意力：`full_attention_interval=4` → 8 层全注意力 + 24 层 gated DeltaNet 线性注意力
- 训练上下文 262144

**解码速度的物理上限**（每 token 必须完整读一遍权重）：

```
tok/s_max = 带宽 ÷ 5.48 GB

LPDDR4X-4266 64-bit : 34.1 ÷ 5.48 = 6.2 tok/s  ← 100% 效率硬顶
LPDDR5-4800  64-bit : 38.4 ÷ 5.48 = 7.0 tok/s
按实测 70% 效率      : 4.3 ~ 4.9 tok/s
```

| 参照 | 带宽 | 实测/推算 9B Q4 速度 |
|---|---|---|
| RK3588S + LPDDR5-4800 | 38.4 GB/s | **~4.9 tok/s** |
| 开发用 PC（X9 388H + LPDDR5X-9600） | 153.6 GB/s | **12.2 tok/s（实测）** |
| 30 tok/s 所需 | **196 GB/s** | 本预算无法达到 |

## 5. USB 复合设备是本方案的核心

Windows 11 已禁用 U 盘 AutoRun，因此"插上自动装"的可行路径：

1. 盒子枚举为**复合 USB 设备**：大容量存储（安装介质）+ RNDIS/CDN-NCM（模型 API 网络口）
2. 用户在 U 盘分区里双击 `安装.exe`（一次性）
3. 安装程序：拷贝 agent → 写配置指向盒子模型端口 → 建桌面快捷方式 → 启动
4. 之后 agent 通过 USB 网卡访问盒子上的 OpenAI 兼容端点

**【待核对】** Windows 侧驱动与枚举实测（RNDIS 在 Win11 上的兼容性）。

## 6. PCB 叠层与工艺

| 项目 | 值 | 依据 |
|---|---|---|
| 层数 | **10~12 层**（8 层为激进下限） | Rockchip 官方：RK3588 使用 10 层 1 阶 / 10 层 2 阶 / 8 层通孔 |
| 过孔工艺 | **盘中孔（树脂塞孔 + 电镀盖帽）** | 嘉立创免费标配；BGA 0.4mm 间距必需 |
| 表面处理 | 沉金 2U" | 嘉立创标配 |
| 阻抗控制 | 差分 50Ω±10%，DDR 等长 | Rockchip 设计指南 |
| 板厚 | 1.6mm，FR-4 Tg≥170°C | 参考华为载板规格 |

**DDR 布线硬约束（Rockchip 官方要求）**：
- **必须使用瑞芯微原厂 DDR 模板 + 对应 DDR 固件**
- **DQ/CA 顺序不可交换**
- ZQ 电阻 240Ω ±1%；ODT_CA 10kΩ ±5%
- 每 ≤2 引脚配一个 GND 过孔
- 相邻层必须是完整 GND 平面

## 8. 项目风险

| 风险 | 影响 | 应对 |
|---|---|---|
| **拿不到 DDR 模板/固件** | 板子无法点亮 | 下单芯片前先向代理确认 |
| **单颗芯片焊接失败** | 项目停摆等货 | 走嘉立创 SMT（有 X-Ray + 维修台），勿手工焊 |
| **0.4mm 间距 BGA 工艺** | 良率风险 | 确认嘉立创工程费与能力 |
| **USB 复合设备在 Win11 兼容性** | "插上自动装"失败 | 先做软件验证 |
| **预算缺口** | 无法投板 | 分阶段：先验证软件，后投硬件 |
| **速度仅 ~4.9 tok/s** | 体验低于预期 | 已确认接受；或改小模型（3B 可到 12~15 tok/s） |

## 10. 已排除的方案（附原因，避免重复调研）

| 方案 | 排除原因 |
|---|---|
| **华为昇腾 310B** | 无 LPDDR5（仅 LPDDR4X-4266）；CANN/llama.cpp 不支持 310B；Q4_K_S 无执行路径；维护者明确"does not support Ascend310B now" |
| **纯 FPGA 跑模型** | 需自研全套 RTL（含 GGUF 加载器），2~5 人年；HBM 版 FPGA 芯片 ¥15K~100K |
| **BM1688** | 最高 16GB LPDDR4X 64-bit（34.1 GB/s，同 RK3588 相当）；官方 Qwen3.5 仅上到 4B；不吃 k-quant；核心板 ¥1200~2400 超预算 |
| **兆芯 KX-7000** | 双通道 DDR5 = 128-bit = 89.6 GB/s，达不到 30 tok/s |
| **256-bit LPDDR5-9600 方案** | 该内存控制器只在 Intel Core Ultra / Snapdragon X / Apple M 上，均不零售裸片 |
| **Strix Halo / DGX Spark** | 可达 30 tok/s，但为整机 ¥14,000 / ¥34,000 |
