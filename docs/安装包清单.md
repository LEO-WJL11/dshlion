## 桌面版和后端的关系（别装重）

- 桌面版**已经包含**后端，装它一个就够；
- 想让浏览器访问、又不想开桌面窗口的，装主安装包；
- 两个包都装也行：桌面版会先探测 `http://127.0.0.1:8080`，已经在跑就直接挂上去，不会重复起后端。

## 已知限制

- **桌面版（178.79 MB）没有进 git 仓库**：GitHub 单文件硬上限是 100 MB，超了直接拒绝 push。
  它躺在 `installer/release/LionBox-Desktop-1.5.0-Setup.exe`（本地已验过），要对外发得走
  **GitHub Releases**（Release 附件没有 100 MB 限制）。三个小包（主程序 74 MB + 两个插件包）
  都在仓库里。
  想让桌面版也能进仓库的话，把 `desktop/electron/electron-builder.yml` 里
  `staging-backend/runtime-jre`、`runtime-vulkan` 两条 `extraResources` 注掉重打即可：
  包会掉到 ~78 MB，但那时它要求机器上有 Java 21+，或者先装过主程序（主程序自带 JRE）。
- 包**没有代码签名**：Windows SmartScreen 首次运行会拦一下（"更多信息 → 仍要运行"）；
  正式对外分发建议配证书（Electron 侧 `CSC_LINK`/`CSC_KEY_PASSWORD`，
  JetBrains 侧 `CERTIFICATE_CHAIN`/`PRIVATE_KEY`）。
- 桌面版用的是 Electron 默认图标；主安装包用的是 LionBox 图标。
- 模型权重不随包发布（太大），首次使用自动从 ModelScope 下载。
