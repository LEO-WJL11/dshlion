## 桌面版怎么拼回来（178.79 MB 那份）

GitHub 单文件硬上限 100 MB，桌面版一次塞不进去，所以切成两片跟着仓库走。
把 `LionBox-Desktop-1.5.1-Setup.exe.part1`、`.part2` 和 `拼装桌面版.bat` 放同一个目录，
**双击 `拼装桌面版.bat`** 即可；它用 `copy /b` 按顺序拼接，并打印期望的 sha256。

手动拼也一样（在放分卷的目录里执行）：

```powershell
copy /b LionBox-Desktop-1.5.1-Setup.exe.part1+LionBox-Desktop-1.5.1-Setup.exe.part2 LionBox-Desktop-1.5.1-Setup.exe
certutil -hashfile LionBox-Desktop-1.5.1-Setup.exe SHA256
# 期望 AB0E5A3F47377B34BEF960371F92958815CAE449C4205B5058829528F9E84A65
```

切分/校验脚本在 `tools/release/_split_desktop.py`（切完自己拼一遍比对 sha256，对不上直接报错，
不会留下"看着拼好了其实是坏的"exe）。

## 桌面版和后端的关系（别装重）

- 桌面版**已经包含**后端，装它一个就够；
- 想用浏览器访问、不开桌面窗口的，装主安装包；
- 两个都装也行：桌面版会先探测 `http://127.0.0.1:8080`，已经在跑就直接挂上去，不重复起后端；
  它找 Java 的顺序是「环境变量 → 包内 runtime-jre → 主安装目录的 runtime-jre → PATH」。

## 已知限制

- **桌面版是分卷进仓库的**（两份 .part 各 <100 MB）：GitHub 单文件硬上限 100 MB，
  178.79 MB 一次塞不进去，Release 附件虽然没这个限制、但传 Release 需要 token（这台机器上没有）。
  拼装见上面那一节。**实测过"瘦身"这条路走不通**：去掉自带的 JRE + llama.cpp 运行时（101 MB）
  后还剩 137.88 MB —— Electron 本体压缩后就约 138 MB，照样超线。瘦包配置
  `electron-builder.slim.yml` 保留着，用于减小下载量，但需要机器上有 Java 或装过主程序。
- 包**没有代码签名**：Windows SmartScreen 首次运行会拦一下（"更多信息 → 仍要运行"）；
  正式对外分发建议配证书（Electron 侧 `CSC_LINK`/`CSC_KEY_PASSWORD`，
  JetBrains 侧 `CERTIFICATE_CHAIN`/`PRIVATE_KEY`）。
- 桌面版用的是 Electron 默认图标；主安装包用的是 LionBox 图标。
- 模型权重不随包发布（太大），首次使用自动从 ModelScope 下载。
