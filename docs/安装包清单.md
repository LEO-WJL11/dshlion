## 桌面版：从 Electron 换成 Tauri（178.79 MB → 2.84 MB）

原来那版用 Electron 套壳，安装包 **178.79 MB**，还得切成两片才进得了 GitHub（单文件 100 MB 上限）。
体积全在"包里带了一个完整的 Chromium"。

现在换成 **[Tauri 2](https://tauri.app/start/)**：界面交给**系统自带的 WebView2** 渲染，
包里的浏览器那 170 多 MB 就没了。**客户端一行没重写** —— 窗口加载的还是后端在
`http://127.0.0.1:8080` 发的那份 WebUI，和浏览器里打开的是同一份代码、同一个页面。

| | Electron（旧） | Tauri（现在） |
| --- | --- | --- |
| 安装包 | 178.79 MB（还要分片） | **2.84 MB**（单文件） |
| 壳本体 | 解包后 ~250 MB | 3.17 MB exe |
| 渲染引擎 | 自带 Chromium | 系统 WebView2（Win10/11 自带） |
| 构建工具链 | Node + electron-builder | Rust + MSVC（这台机器已有 Build Tools） |
| 进不进得了仓库 | 进不去，只能 Releases | 直接进，两个仓库都有 |

对照过的其它小体积方案（详见 `docs/发布形态.md`）：[Neutralinojs](https://neutralino.js.org/)
（官方定位就是"简单套壳里最小的"）、[Wails](https://v3.wails.io/zh-cn/faq/)（Go + WebView2）、
[Electrobun](https://github.com/blackboardsh/electrobun)（Bun + 系统 WebView）。
选 Tauri 的理由：同样"用系统 WebView、不打包浏览器"，但生态和文档最成熟，且这台机器上
MSVC 工具链已经就位，构建只需要装一个 Rust（约 300 MB）而不是几 GB 的 VS Build Tools。

## 桌面版和后端的关系（别装重）

- 桌面版**不自带后端**：它用主程序（WebUI 版）装好的 jar + 精简 JRE 起服务，
  找不到主程序时窗口里会直接说明白要先装什么（不会给个白屏让人猜）；
- 找 Java 的顺序：`LIONBOX_JAVA` 环境变量 → 主程序安装目录的 `runtime-jre` → PATH 里的 java；
- 想换端口/连别的实例：设 `LIONBOX_URL`（例如 `http://127.0.0.1:9000`）；
- 两个包都装也没问题：桌面版先探测 `127.0.0.1:8080`，已经在跑就直接挂上去。

## 验证记录

- `LionBox-Setup-1.5.1.exe`：ISCC 出包 → 静默装 → 用**装出来的自带 JRE** 起 jar →
  页面/插件/技能/@ 端点全通。见 `tools/release/_finalize_151.py`。
- `LionBox-Desktop-1.5.1-Setup.exe`：装到临时目录 → 用**装出来的那份 exe** 跑自检
  （地址解析、后端探测、jar/JRE 定位、系统 WebView2 版本）→ 卸载干净。
  见 `tools/release/_verify_desktop_install.py`。
  **窗口渲染这一步在这个环境里验不了**：WebView2 的宿主与浏览器进程之间走命名管道通信，
  在受限的自动化会话里起不来（实测 Tauri 报 `0x8000FFFF`、手写的 .NET 宿主直接 CLR 崩溃，
  而同一台机器上 Edge headless 完全正常）。这一下要在真实桌面上双击看。
- 两个 IDE 插件包：结构验证（`plugin.xml` / 类 / 清单 / 命令 / 配置齐全）。

## 已知限制

- 桌面版**要求系统有 WebView2 运行时**：Windows 10/11 自带（这台机器上是 154.0.4258.48）。
  万一没有，壳会在窗口里显示"请先装 WebView2 运行时"和官方下载地址
  （这个提示故意放在应用里而不是安装程序里：安装脚本里加 [Code] 检查一旦闪失，
  Inno 会直接 exit=1、连日志都不写、一个文件都不装 —— 实测踩过，所以安装脚本保持最简）。
- 包**没有代码签名**：Windows SmartScreen 首次运行会拦一下（"更多信息 → 仍要运行"）。
- 桌面版用的是自绘占位图标（`tools/dev/_make_icon.py` 生成），有正式设计稿直接替换
  `desktop/tauri/src-tauri/icons/icon.ico` 重编即可。
- 模型权重不随包发布（太大），首次使用自动从 ModelScope 下载。
